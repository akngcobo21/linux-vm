# linux-vm
This project builds a Client-Server Architecture operating over a Wide Area Network (WAN) using the HTTP (Hypertext Transfer Protocol).

An HTTP web application program written in C# and .NET 8 was deployed to a virtual computer operating system (Linux Ubuntu 24.04 LTS) hosted on Microsoft's cloud infrastructure (Azure). A client machine running Windows sends requests to the remote Linux machine across the public Internet to test cross-platform inter-process communication.
